# Frontend Internship Project

This is a simple beginner-level frontend project built using HTML and CSS.  
It was created as part of a frontend internship to practice basic web development skills.

## 🚀 Features
- Responsive design
- Clean and simple UI
- Basic layout using HTML & CSS

## 🛠️ Technologies Used
- HTML5  
- CSS3  

## 📁 Project Structure
- index.html → Main webpage  
- style.css → Styling file  
- images/ → Project images  

## ▶️ How to Run This Project

1. Download or clone this repository  
2. Open the project folder  
3. Double-click on `index.html`  

The project will open in your browser.

## 💡 Note
This is a beginner project made for learning purposes during internship.
